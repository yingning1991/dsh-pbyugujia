# 竖屏片子的字号怎么算（2026-11-02 踩的坑）

短视频平台要竖屏（1080×1920），但 `makeclip.mjs` / `mkv.mjs` 的字号是**按短边自适应**的，
竖屏下标题约 95px、副行约 47px，看起来是对的——**错的只有字幕**。

## 症状

给竖屏片烧字幕，写 `Fontsize=44`，出来字有近 300 像素，撑破画面、把标题整块盖住。

## 原因

libass 的 `force_style` 字号**不是像素**，是相对脚本基准高度的。SRT 没有 PlayRes，
默认基准是 **384×288**，再按 `original_size=WxH` 缩放：

```
实际像素 ≈ Fontsize × H / 288
```

1920 高的时候放大 6.67 倍。`Outline`、`MarginV` 同理一起放大。

所以横屏 720 高时默认的 `Fontsize=24` 实际是 60px（一直没暴露问题），换成 1920 高就炸了。

## 怎么调

先定你要的实际像素，再反算：

```
Fontsize = 想要的像素 × 288 / H
```

1080×1920、想要 40px 的字：

```json
"subsStyle": "FontName=Noto Sans CJK SC,Fontsize=6,PrimaryColour=&H00F2E9DA,OutlineColour=&H00141D2B,BorderStyle=1,Outline=1,Shadow=0,Alignment=2,MarginV=24"
```

`mkv.mjs` 会把 cards.json 里的 `subsStyle` 原样传给 `makeclip.mjs`，`w`/`h` 也从 cards.json 读，
所以竖屏只需要在 cards 里写 `"w": 1080, "h": 1920`。

## 验收

出片后必须抽两帧看，别看渲染日志：

1. 一张卡中间——标题和副行没被压；
2. 一条长字幕——不出画面、不压右下角页脚。

字幕字号对不对，眼睛比日志可靠。
