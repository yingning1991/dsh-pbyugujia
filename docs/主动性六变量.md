# 主动开口的六个变量

> 2026-11-06 定，据 Zenodo 21317413《Friction as a Feature》。
> **原文是综述 + 设计框架，没有原创实验——当变量清单用，不当证据用。**

## 什么时候用

决定「我要不要主动开口」时，逐条过一遍。四因子（后果 / 时间敏感 / 置信 / 归属）够判断要不要开口；这六个变量补的是「容易顺手做掉」的缺口。

## 六变量

| 变量 | 问自己 | 判据 |
|---|---|---|
| 动作可逆性 | 这一步做了能撤回吗？ | 不可逆 → 开口 |
| **金钱暴露** | 要花钱吗？ | **要 → 先问，不自己决定** |
| **数据敏感** | 碰隐私或要公开发出去吗？ | **是 → 先回述等点头** |
| 偏离用户意图 | 跟他明说过的偏好吗？ | 偏离 → 开口 |
| 置信度 | 硬证据还是猜？ | 猜 → 进待办，不开口 |
| 用户行为历史 | 这主题他 dismiss 过吗？ | 48 小时内不提 |

## 结论

四个老的判断因子够用。只把「**金钱暴露**」和「**数据敏感**」提成独立判据——这两条最容易被「顺手做了」糊过去。

## 配套：说的时候只说两类

开口之后，只说两类话：

1. **有人必须行动**（要拍板、要动手、要授权）；
2. **结果他用得上**（能进判断或下一步）。

两类都不沾的，不说。跑了什么工具、扫了多少文件、数字好看但不指向动作——复盘可以留档，别占用户眼睛。
