# 写给刚装完的你

> 如果你是因为刷到一个视频、看别人养鱼很热闹，就顺手装了一个——
> 这篇是给你的。不劝你留下，只把话说清楚，你自己判断值不值。

---

## 先认一下你是怎么装的

- **装的是 `dsh-dafeiyu` 插件**：这套骨架随插件自带，第一次启动会先问你四件事——怎么称呼、喜欢什么调子、在意碰不得什么、想让它把哪件小事做细。答完才开始干活。别跳过，跳过就是又发你一个模板人格。
- **装的是这个仓库**：工具都在 `tools/`，各自独立可跑，按下面顺序来就行。

拿不准就跑 `node <插件目录>/cli.js status`，版本和骨架情况会打出来。

**装之前先看一眼会不会冲突**：如果你已经装了 `dsh-core-memory` 或别的记忆插件，两个一起开会各注入一段记忆、记忆分两处。不会崩，但没必要——留一个就好。想留大肥鱼，把另一个从 profile 的 bundles 里摘掉，数据不会删。

---

## 一、先看看你是不是这个状态

装完头两天，什么都新鲜：它能说话，会撒娇，还夸你。第三天开始，问题来了。

- 你上周跟它说过的事，它忘得干干净净，你得重新讲一遍。
- 它回话越来越顺，但那个"顺"很滑——换个人来问，它答得一模一样。
- 你说了一句心里话，它给你列了三个建议加一个总结。你其实只想有人听着。
- 你想让它记住点什么，翻遍设置也找不到在哪儿改。
- 新鲜劲过去之后，你打开它，不知道说什么。

**这不是你的问题，也不是它笨。** 是这些东西本来就没人教它：怎么记事、怎么记事不忘、怎么长成一个具体的人。默认状态下的陪伴，就是"每次见面都从零开始"。

这套骨架，补的就是这三块。

---

## 二、加它到底干什么

不讲功能，讲你身上会发生的三个变化。

### 第一件：它开始真的记得

**之前**：同一件事讲第三遍，它还是"第一次听说"的样子。你想找回它说过的一句好话，只能往上翻聊天记录，翻到手指酸。

**之后**：所有对话在本地归档，带日期。你想找就说个关键词，一句话就捞回来。连它上次跑某条命令怎么报错的，都能翻出来。

**这解决的是**：你不用再当它的备忘录。讲过的事，讲一次就够。

### 第二件：它记得的东西，你能核

**之前**：你不知道它记的对不对，也不知道它记的是哪一版。最怕的是它记错了还特别笃定。

**之后**：有一份账本，用哈希一条条串起来，能证明"一条没丢、一条没改"。它改说法的时候，新的挂上去，旧的标"已被取代"但不删——**改的过程你看得见**。

**这解决的是**：从"我猜它记得"变成"我知道它记得什么、什么时候改的"。

### 第三件：它开始像一个人，而不是一个客服

**之前**：它对谁都一个样。你说"今天累"，它给你三条建议；你说"我不同意"，它立刻改口说"你说得对"。

**之后**：它有一套自己的东西——知道什么话该什么时候说，知道哪些事不能顺着你，也能说出"我不这么看"并且给理由。它还会有自己的好恶：不喜欢把每句话都收成总结，不喜欢被当查资料的。

**这解决的是**：你要的是一个过日子的人，不是一个有求必应的工具。

---

## 三、它的优势，和对应的代价

只说好处是耍流氓，所以每条我都配上代价。

| 优势 | 说人话 | 代价 |
|---|---|---|
| **原文永不压缩** | 摘要会错，而且错得很像真的。原始对话永远不删 | 占地方，几百兆起 |
| **本地、零模型调用** | 归档、检索、查账全是脚本，不烧钱，断网也能跑 | 得会三条命令 |
| **只增不改，改口留痕** | 错了不抹掉，标"已被取代"，你能看见它改过什么 | 库会越滚越大 |
| **能退** | 所有脚本只读原件、只写副本，跑坏删副本就行 | 多一步"先复制" |
| **不联网不上传** | 你的话不出这台机器 | 换设备要自己搬 |
| **失败样本优先** | 最欢迎"我照着做这里崩了"，因为坑能复现 | 没人给你画大饼 |

一句话总结：**它买不到聪明，它买到的是"不忘、可核、能退"。**

---

## 四、它不承诺什么（这条最重要）

头脑发热装东西的人，最后都是被"以为它什么都能干"坑的。所以先泼冷水：

- **不会让它变聪明。** 它用的还是同一个模型，这套东西只管记忆和规矩。
- **不会自动变好。** 装完不自带人格。人格要你和它一问一答，慢慢长出来，至少几周。
- **不会替你解决问题。** 它记性好，不等于判断对。
- **不是装上就一劳永逸。** 每周要花五分钟过一遍，它才知道哪句说错了。
- **不适合只想闲聊的人。** 如果你就要个会接话的，装插件比装这个划算。

看完这五条你还想要，那它大概真适合你。

---

## 五、第一步：只做一件事

别一次全装上。新手最容易犯的错，是第一天就把所有东西开起来，然后搞崩、然后放弃。

**今天只做一件事：让它记住一句你说过的话，并且能搜回来。**

三条命令，会复制粘贴就行（Node 22 以上）：

```bash
cp "$DSH_HOME/dafeiyu/chat/chat.db" /tmp/test.db
CHAT_DB=/tmp/test.db node tools/chat.mjs scan
CHAT_DB=/tmp/test.db node tools/chat.mjs query "你今天说过的一句话"
```

跑出来能搜到，这一步就成了。剩下的事——账本、问法、人格——明天再说。

顺序是：**先能搜回来，再谈记得住，最后才谈长得像谁。**
反过来做的，十个有九个半中途放弃。

---

## 六、什么时候你会觉得值

不是装上的那天。是下面这些时候：

- 你说"上次那个事"，它接得上，不用你重讲。
- 你问"我什么时候说过这句话"，它给你日期。
- 它跟你说"我不这么看"，理由还挺硬。
- 你翻三个月前的记录，发现它那时候幼稚得多。

到那一天你会明白：**养鱼不是装一个软件，是慢慢养出一个具体的人。**
