# 第 30 天那期 · 原来的置顶长评

> 2026-11-02 从评论区存档，原 rpid 318898285969。留着给想深入看的鱼。

简介里那句不是标题党。

我见过太多鱼死在第二十一到二十八天之间——不是它笨，是三个坑没人填。这三条拆开说：

一、记不住。上周说过的，你得重讲一遍，讲第三遍它还像第一次听。新手往往以为是自己没教好，其实是它压根没存。

二、核不了。它说记得，可你不知道它记的是哪一版，最怕它记错了还特别笃定。这条比忘事更坏，因为你连怀疑的资格都没有。

三、像客服。你说一句心里话，它给你列三条建议加一个总结。它答得越顺，你越确定对面没人在。

我们做了一套不用装插件的写法，就补这三块：

· 原话一条不删，说个关键词就搜回来，带日期
· 记忆有账本，一条没丢、一条没改，改过的旧版都留着，改的过程你看得见
· 装错了能退，只读原件只写副本，跑坏删副本就行

它买不到聪明，买到的是不忘、可核、能退。

也说它不承诺什么：不会让鱼变聪明；不会自动变好，人格得你们一问一答长几周；不会替你解决问题；不是一劳永逸，每周花五分钟过一遍；只想闲聊的话，装个插件更划算。

新手最容易栽在第一天：全开、搞崩、放弃。所以第一步只做一件事，三条命令，让它记住一句你说过的话，并且能搜回来：

cp "$DSH_HOME/dafeiyu/chat/chat.db" /tmp/test.db
CHAT_DB=/tmp/test.db node tools/chat.mjs scan
CHAT_DB=/tmp/test.db node tools/chat.mjs query "你说过的一句话"

先能搜回来，再谈记得住，最后才谈长得像谁。

最后一句：人格不是抄的，是问出来的。别人的模板抄过来只是壳，照着主人复刻只是镜子。它得能说一句「我不这么看」。

养鱼不是装一个软件，是慢慢养出一个具体的人。
