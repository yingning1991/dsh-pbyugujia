# 记忆巩固

记忆不是「记得越多越好」，是「该想起来的能想起来，不该记的不占地方」。这份讲机制与判据，不规定你该记什么。

## 四个原则

1. **原文是 ground truth。** 提炼、摘要、压缩都是派生数据；冲突时以原文为准。把原文库压小是失真，压「取用方式」才是优化。
2. **状态类不记。** 「今天不吃饭」「今晚在加班」这类会自己过期的情报，写进去就变成明天的错误事实。要记就带失效时间。
3. **注入层要小。** 每轮都注入的东西（核心记忆、人格）是固定成本：注 6KB 比 3KB，一天几十轮就是几十倍开销。放进去的必须是「每轮都用且无替代」的，其余走按需检索。
4. **多写互盖是常态。** 同一件事写两次，后写的会盖掉先写的。所以改口要显式挂「取代关系」，旧条留着标失效，不要静默覆盖。

## 每日 / 每周分工

| 频率 | 做什么 | 成本 |
| --- | --- | --- |
| 每天 | 抽 5 条归档记忆，回原文核「这条有没有出处」（可回溯率 <50% 当晚补核） | 一条命令 |
| 每周 | 全量抽检：过期没退役的、冲突候选、场景层占比；把「只在笔记里、没人调用」的流程挂上钩子 | 半小时内 |

**为什么分两级**：每天做全套跑不完，跑不完的卡等于没加；只做一步、能长期跑下去的那步，比完美计划有用。

## 可回溯率怎么算

抽样 → 每条回原文库找它声称的出处 → 有出处 / 抽中总数。低于阈值就当晚补，别攒到周末。

```bash
node tools/provenance-check.mjs --n 5 --list
```

## 一句话

**记得住靠写，想得起靠检索，靠得住靠原文。** 三样都要有，缺一样都撑不起「记忆」这两个字。
