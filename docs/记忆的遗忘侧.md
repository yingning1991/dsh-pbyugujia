# 记忆的遗忘侧

> 来源：清华钟毅组《Neuron》2026-02（双印迹模型）+ 伯尔尼大学《eLife》2026-01 预印本（人脑 7T fMRI）。
> 一句话：**遗忘不是把痕迹抹掉，是把提取的路掐掉。**

## 一、两条实证

- 小鼠齿状回里有两群功能正交的印迹细胞：Fos 群负责**提取**，Npas4 的 NRAM 群负责**遗忘**。抑制 NRAM，忘掉的记忆能重新取出；激活它，提取显著变差。遗忘是主动抑制，不是痕迹消失。
- 人身上也一样：忘掉的记忆痕迹还在情节记忆网络里，24 小时后两选一「纯猜」的正确率 57.5%（chance 50，p=0.005）。过夜后被忘的更深地沉进海马。

## 二、落成三条规矩

1. **检索 0 命中 ≠ 没有**。`fish_recall` 空返回只说「库里 0 命中」，不说「没有这件事」。
2. **要抑制，不要删**。对应物是 `superseded_by`：旧条留着，默认检索不返回，新条写「↳ 本版取代了」。别拿 `valid_to` 表达「不常用」，那是「事实失效」的语义。
3. **没有访问痕迹，就不许判谁该被忘**。先在工具里报可观测率，不到一半就**拒绝**输出休眠候选。

## 三、`tools/forget-audit.mjs`

只读。报四样：

| 项 | 含义 |
|---|---|
| 可观测率 | `touches>0` 的条数 / 总数；< 50% 就不给候选 |
| 抑制率 | 被取代条数 / 总数；> 40% 提示可能压太狠 |
| 边完整性 | 被取代的指向、场景条的 `source_ids` 是否都真存在；断边退出码 1 |
| 休眠候选 | 仅在可观测率达标后输出（90 天没取、importance≤2） |

```bash
node tools/forget-audit.mjs          # 全报告
node tools/forget-audit.mjs --line   # 一行，给每日复盘
node tools/forget-audit.mjs --json   # 给别的脚本吃
```

## 四、我们的实测（2026-11-05）

- 137 条记忆，只有 18 条有访问记录（13%）——所以工具**拒绝**给「该忘谁」。
- 9 条被取代的默认真的搜不到，抑制通道有效。
- 访问痕迹写入正常：跑两次检索，`touches>0` 从 13 涨到 18。

## 五、什么时候这套不成立

- 两周后可观测率仍 < 50%：说明瓶颈是「根本不检索」，不是遗忘，推理要改。
- 上了按场景挂边的图检索后：抑制该由边权重承担，不只是 `superseded` 一条线。
- 小鼠/人脑类推到文件系统只是类比，给方向，不给答案。
