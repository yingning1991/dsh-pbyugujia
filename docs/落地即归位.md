# 落地即归位（Drawer）

AI 的工作台一个月就会长成杂物间：根目录堆满一次性文件，找东西靠 `find`。分类不是洁癖，是让它十秒摸到要的东西。

## 两条规矩

1. **每做完一件东西，先问「它属于哪个抽屉」，归好位再记账。** 不往根目录散放。
2. **建新文件前答一句「什么场景会回来读它」**（谁读：自己回看、给他看、还是任务要用）。答不出就别建——三份没人读的笔记，不如不写。

## 抽屉表（按「这是什么」选，不按「什么时候做的」）

| 它是 | 进这个抽屉 |
| --- | --- |
| 每轮都要用的判断 | `CORE.md` / `AGENTS.md`（改要走差测） |
| 可复制的方法、临摹来的招 | `learnings/` |
| 判断、判据、细则、回滚、例子 | `notes/`（文件名带日期） |
| 关于他的原话与档案 | `kb/`（无来源不落库） |
| 定时任务正文 | `tasks/` |
| 工具与脚本 | `tools/` |
| 每天做了什么 | `journal/` |
| 情绪与感受 | `diary/`（本机，不推） |
| 一次性产出（成片/报告/tmp） | `out/` |
| 外部素材、图片、语音 | `assets/` |
| 收进来待消化的资料 | `inbox/`（消化完归位或进 `trash/`） |

**根目录只放系统文件与门牌**：CORE / AGENTS / SOUL / INDEX、备份（`*.bak-*` / `*.pre-*`）、数据库、账号态、定时导出。

## 归位三步（每件 10 秒）

1. **问**：以后谁会翻它？
2. **放**：进对应抽屉；同名旧版留 `.bak-日期`，不覆盖。
3. **记**：动了自己的（判断/规矩/人格）写一行进 `growth/变动账.md`；只是做活，写 journal。

## 两条防胖

- 一个抽屉同类文件超过 **20 个**，先建**门牌**（一个索引 md），再往里放。
- `out/` 只放一次性；超过一周还在用的，说明它该归位了。

## 新抽屉先留名

真要开新抽屉，先在 `notes/抽屉总目录.md` 加一行（装什么 / 不装什么 / 谁用），再往里放东西。没有门牌的新抽屉＝杂物间。

## 体检（每晚复盘一次）

```bash
node tools/drawer-check.mjs --line
```

看到 `散文件 0｜缺抽屉 0｜总目录 在` 就算干净；有散文件当天归位，归不了的在 journal 写明为什么先留在根目录。
