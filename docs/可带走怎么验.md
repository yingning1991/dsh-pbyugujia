# 可带走怎么验

这套东西的卖点是「记忆与判断能脱敏带走」。但「应该能带走」和「真的能带走」是两件事——**用一条命令把它验出来**。

## 验什么

1. **文件在不在**：整份工作台拷到临时目录，文件数、字节数对得上。
2. **门牌通不通**：文档里指向 `docs/`、`tools/`、`notes/` 的链接，逐条解析、检查目标存在——报「可达率」。
3. **能不能跑**：随手挑一条工具命令，在临时目录里跑得通（不依赖原路径）。

## 一条命令（可复制）

```bash
# 1) 拷一份到临时目录（不碰原件）
TMP=$(mktemp -d)
cp -a $DSH_HOME/pbyugujia "$TMP/"

# 2) 数一数
echo "文件 $(find "$TMP/pbyugujia" -type f | wc -l) / 大小 $(du -sh "$TMP/pbyugujia" | cut -f1)"

# 3) 解析 markdown 里的相对链接，报可达率
cd "$TMP/pbyugujia"
total=0; ok=0
while IFS= read -r link; do
  total=$((total+1)); [ -e "$link" ] && ok=$((ok+1)) || echo "✗ 断链: $link"
done < <(grep -rhoP '\]\(\K[^)#:]+(?=\))' --include='*.md' . | grep -v '^https\?://' | sort -u)
echo "可达率: $ok/$total"
```

## 判据

- **可达率 100% 才算「能带走」**；断链逐条修，别用「大部分能到」糊过去。
- 断链常见来源：改名没改链接、指向本机绝对路径（`/data/...` 这种必须清）。
- 数字（文件数、大小、可达率）**每次发版重跑**，写进 README 的就是最近一次的真实值。

## 反例

曾经把「24/24 可达」写进介绍，是当时人工数出来的；两周后加了新文档没重跑，链接已经断了两条——**没重跑的数字就是广告词，不是证据**。

## 一句话

**能带走 = 拷到别处 + 门牌全通 + 一条命令跑得起来。** 三样缺一，别写「可带走」。
