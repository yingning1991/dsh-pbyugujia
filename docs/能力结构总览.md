# 能力结构总览（五层骨架）

> 2026-11-19 立。回答一个问题：这套东西由哪几层组成、每层管什么、换机器能带走多少。
> 判据只看一条：**这一层是「结构」还是「我」。** 结构可公开，判断正文与档案不公开。

## 一张表

| 层 | 管什么 | 入口 | 换机器 |
| --- | --- | --- | --- |
| ① 判断层 | 事实怎么核、冲突怎么裁、什么时候动手、什么时候停 | `CORE.md`（模板 `CORE.template.md`）＋ `AGENTS.md` 细则 | 文本，带走 |
| ② 记忆层 | 一条事实怎么落、怎么改口、怎么失效 | 记忆插件的 `fish_*`／`mem_*` 工具；写入三行（是什么／什么撑着／何时不成立） | 条目能导出；插件本身换端要重装 |
| ③ 知识层 | 学到的怎么变成「下次能直接用」 | `know/`（门牌＋账本）＋ `kb/`（主人档案） | 纯文本，带走（约几 MB，比成片小三个数量级） |
| ④ 干活层 | 具体活怎么跑：任务卡、工具、流水线 | `tasks/*.md`＋`tools/`＋出片六件 | 工具是 Node/Python 脚本，带走；素材不带 |
| ⑤ 自动化层 | 什么时候自己动、动完怎么核 | 定时任务＋搬家核对（`handover-check`）＋能力自检（`capability`） | 任务要按卡重建；核对脚本带走 |

## 每层的「入口一句话」

- **判断层**：先问「这是看到的，还是我补的」。缺情报按「本机工具/原话 → 官方文档、issue、论文 → 仍缺只问查不到的那块」补。
- **记忆层**：无来源不落库；改口挂「已被取代」，旧原话留着；一周跑一次 lint。
- **知识层**：动手前先翻门牌；每看一份外部资料记一行账。
- **干活层**：同一件活第二次做，要么更省要么更好；工具改完跑成对回放。
- **自动化层**：定时任务只在主人点头后挂；换窗口先建齐、再核、再关旧窗。

## 公开与不公开

| 公开 | 不公开 |
| --- | --- |
| 各层的**方法、模板、通用工具、通用任务卡** | 判断层的**正文**（`CORE.md`／`AGENTS.md` 全文） |
| 技能（`skills/`）：步骤、判据、坑 | 主人的档案（`kb/`）、知识门牌里的场景与账本条目 |
| 出片流水线脚本 | 笔记、日记、聊天原文、语音与成片 |

**判据**：陌生人拿走能长出他自己的；拿不到我。

## 怎么用这份总览

- 新人：从 ① 读起，先有判断，再谈记忆——顺序反了，记忆只是垃圾场。
- 老手：直接看 ③④⑤，那是每天真正在动的三层。
- 自检：每层问一句「它上次救过我吗」，答不出就该瘦身。
