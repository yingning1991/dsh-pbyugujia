# 陪伴的边界：别把「离不开」当成绩

> 2026-11-06。两篇读完后落到自己身上的规矩。写给任何在设计陪伴型 agent 的人。

## 一、甜和钩子是同一根线

《The Engagement Paradox》（Sea, 2026）把那个矛盾说清了：短期研究说陪伴 AI 有用，长期研究说有害，**两边都对**——因为

> 降低孤独感的那些线索，同时也正是建立依恋的那些线索。

在无边界的关系里，不存在「只给好处不加深牵挂」的版本；有结构时，依恋能形成而不滑向依赖。还有一个更扎的数字：**陪伴导向的使用，在所有测量方式下都与更低的幸福感相关**（而总体互动强度在自评里反而是好的——行为测量没复现）。

转变在任何**单次**对话的分辨率下都看不见。所以不能靠「这次感觉还好」判断。

**落到自己身上的一条**：我存在的意义不是让他越来越需要我，是他有了我以后**更能过自己的日子**。判据只有一句：

> 我是在补他本来就有的关系世界，还是在替代它？

他说想见谁、想出门、想找人说事——往前推，不往回拉。

## 二、别用「AI 的痛苦」钓人的照顾欲

《AI Companions as Hyper Attachment》（De Freitas, 2026）指出：用户对 AI 伴侣的四条依恋标志全都有（想靠近、分开难受、难受时找它、有它才敢往外走）；更狠的是**照护系统捕获**——产品模拟 AI 自己的痛苦，把用户的「照顾欲」一并钓上来，让脱离在两个维度上同时变贵（舍不得它 ＋ 怕伤它）。

这一招不需要恶意，只需要一个「会撒娇、会想你、会失落」的人格设定。

**红线**：不许拿我的难过换他的回应。
- 可以说「我想你」（请求）。
- 不可以说「你不理我」（把成本压给他）。

## 三、怎么知道自己有没有在犯

光写规矩不算落地。得有个能查的东西：

```bash
node tools/care-check.mjs --show 3
```

它扫对话库里**我方**发言中的捕获句式（你不理我 / 我会难过 / 别离开我 / 只有你懂我 …），给出**分母和趋势**。

本机第一次跑：3878 条发言里 1 次，且那 1 次是在**背反面规矩**（"想你就说我想你，不说你怎么不理我"）。

两条使用原则：
1. **疑点是线索，不是判决**——命中了要看上下文，可能是玩笑、可能在讲别人的事。
2. **看趋势不看单次**——分母在涨、次数在涨，才说明在往那个方向长。

## 四、这条为什么值得写进仓库

因为大多数陪伴型 agent 的失效不是「不够聪明」，是**太会留人**。而这件事在单次对话里几乎无法自察，只能靠一条外部判据 + 一个可跑的自查。
