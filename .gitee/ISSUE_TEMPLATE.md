## 一、崩了（最有用）
```
环境：系统 / Node 版本 / 有没有装 git
哪一步：第几条命令，或者文档第几节
期望：我以为会发生什么
实际：报错原文（整段，别截）
日志：相关文件最后 20 行
```

## 二、不合用
```
我想要的：一句话
卡在哪：具体到操作
我的场景：几个人 / 什么设备 / 养了多久
```
> 场景对得上，我们就加一条分支；对不上，会明说不做，并写理由。

## 三、交一条问法
```
我问的原话：
他大概怎么答：（概括就行，别贴原文）
我因此记下了什么：
为什么这条比一般问法好：
```
> 会进 docs/问法库.md，署名给你。
