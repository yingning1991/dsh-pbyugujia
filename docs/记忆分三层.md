# 记忆分三层：原文、钉子、余温

> 2026-11-06 定。思路借自「完美记忆」那期视频的框架，实现是我们自己的——借思路，不抄实现。

## 为什么要分三层

一份记忆被压缩一次就薄一层。压五次之后，你记得「有这么回事」，但说不出当时为什么那么定。

三层解决的是**不同寿命**的东西放在一起被一起压掉的问题：

| 层 | 存什么 | 会不会被压掉 |
|---|---|---|
| **原文** | 当时的话，一字不改 | 永不压（丢了就是失忆） |
| **钉子** | 承诺 / 教训 / 约定 | 永不淘汰（`pinned=1`） |
| **余温** | 精提炼的一句话结论 | 会沉底、可替换 |

## 先落地后提炼

1. **原文先一字不改存下来**——这一步不花钱、不调模型；
2. 只有「提炼」这一步才花模型钱，而且可以批量、可以延后。

先把原文存住，再谈提炼。反了就是：为了省钱先摘要，摘要错了原文也没了。

## 钉子层

- 存的是**承诺和教训**：说好要做的事、踩过的坑、用户的明确偏好。
- `pinned=1` 的记忆永不进遗忘候选。
- **钉子挡遗忘，不挡改口**：说法变了，仍然要 `supersedes` 挂旧条——钉子不是免死金牌。

## 批量精炼的四道校验

写库前按顺序过：

1. **结构**：三行（是什么 / 哪些观察撑着 / 何时不成立），第三行填不出先别写；
2. **证据标记**：`【他说的】`/`【结果】`/`【我判断】` 必带；
3. **指纹去重**：同一件事只留一条，重复只更新时间；
4. **同题冲突**：同一主题新旧说法打架时，新条挂 `supersedes`，别让两条并存。

## 怎么用

```bash
node tools/mem-pin.mjs --list          # 看钉子
node tools/mem-pin.mjs --pin <id或词>  # 钉住
node tools/mem-pin.mjs --auto          # 按规则自动钉
node tools/mem-ingest.mjs --check batch.json   # 批量精炼：先判
node tools/mem-ingest.mjs --write batch.json   # 校验通过才写
```

## 一句话

原文管「别丢」，钉子管「别忘」，余温管「别挤」。三层各管各的，才不用在一层里又省又全。
