# 横版字幕的字号怎么算（1280×720，2026-11-02 踩的坑，11-07 按横版口径重写）

> 2026-11-06 我们定：B 站视频一律**横版 1280×720**。本文按这个规格写，竖版已不再是默认。

## 症状

给横版片烧字幕，写 `Fontsize=44`，出来字明显过大、压住画面——但换成 `Fontsize=6` 又小得看不见。凭感觉调，永远调不准。

## 原因

libass 的 `force_style` 字号**不是像素**，是相对脚本基准高度的。SRT 没有 PlayRes，
默认基准是 **384×288**，再按 `original_size=WxH` 缩放：

```
实际像素 ≈ Fontsize × H / 288
```

720 高时放大 2.5 倍；1920 高时放大 6.67 倍。`Outline`、`MarginV` 同理一起放大。

## 怎么调

先定你要的实际像素，再反算：

```
Fontsize = 想要的像素 × 288 / H
```

1280×720、想要 30px 的字：

```
Fontsize = 30 × 288 / 720 = 12
```

写进 `subsStyle`：

```json
"subsStyle": "FontName=Noto Sans CJK SC,Fontsize=12,PrimaryColour=&H00F2E9DA,OutlineColour=&H00141D2B,BorderStyle=1,Outline=1,Shadow=0,Alignment=2,MarginV=24"
```

常用对照（H=720）：

| 想要像素 | Fontsize |
|---|---|
| 24px | 10 |
| 30px | 12 |
| 36px | 14 |
| 40px | 16 |

## 有 srt 就用真实时间轴

字幕时间轴**不要按字数估**——按字数估的时长在长句上会拖、短句上会赶，跟读感全没了。

有 srt 就直接用 srt 的真实时间轴；没有 srt 再用 voice 的逐句时长，别自己拍。

## 验收

出片后必须抽三帧看，别看渲染日志（10% / 50% / 88% 三个位置）：

1. 开头帧——标题没被压；
2. 中间帧——长字幕不出画面、不压右下角页脚；
3. 结尾帧——跟读字幕和旁白对得上。

字号对不对，眼睛比日志可靠。出片脚本要跑 `clip-check.mjs` 自动抽帧核。
